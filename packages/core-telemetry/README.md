# `packages/core-telemetry`

Polyglot shared package — the **only** legal coupling point between
`apps/edge-daemon`, `apps/cloud-backend`, and `apps/paddock-dashboard`.
Anything that needs to be agreed on across runtime boundaries lives
here: telemetry schemas, the Domain Expertise Layer (DEL) math
contracts, VBO parser, track metadata loaders, and the canonical
learning-plan JSON shape.

If a feature requires the same struct to exist in Python *and*
TypeScript, that struct's authoritative definition is a JSON Schema
under `schemas/`. Both language wrappers are derived from it (manual
hand-write for now; codegen lands once `tools/openapi-extract.py` is
written).

## Domain Expertise Layer (DEL) — the contract surface

The DEL lives here, not inside any app, because all three apps consume
it. From PRD §4:

> The DEL must eliminate book-reading pedantry by replacing generic
> string-matching text rules with structured, multi-tier driving logic.

### 1. Corner Phase State Machine

Maps `(lat, lon, heading, speed, distance)` → `CornerPhase` ∈
{`Entry`, `Apex`, `Exit`, `Straight`}. Coaching cues generated for
`Entry` are wiped if the vehicle has already transitioned to `Apex`
or `Exit` — implemented as a single pure function so both edge
(Python) and paddock dashboard (TS) compute the same result from the
same frame.

```python
# python/core_telemetry/corner_phase.py
def classify(frame: TelemetryFrame, track: Track) -> CornerPhase: ...
```

```typescript
// typescript/src/corner_phase.ts
export function classify(frame: TelemetryFrame, track: Track): CornerPhase
```

Both implementations are spec-tested against the same `tests/golden/`
fixture set so divergence is caught in CI.

### 2. Gold-Trace Delta

Loads a reference lap (`gold_trace.schema.json`) per car × track, then
exposes:

```python
delta = CornerDelta.compare(
    actual=lap,
    reference=gold_trace,
    phase=CornerPhase.Entry,
)
# CornerDelta(brake_point_m=-12.4, entry_speed_kph=-3.1, slip_angle_deg=+0.8)
```

The LLM **never** sees raw channel values — it sees `CornerDelta`
instances. That is what unlocks the "Carry more entry speed" cue
instead of "you are braking early."

### 3. Pedagogical Cue Format

```json
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "type": "object",
  "required": ["text", "phase", "severity", "word_count"],
  "properties": {
    "text": { "type": "string", "maxLength": 80 },
    "phase": { "enum": ["Entry", "Apex", "Exit", "Straight"] },
    "severity": { "enum": ["info", "nudge", "warn", "critical"] },
    "word_count": { "type": "integer", "minimum": 1, "maximum": 7 },
    "source_delta": { "$ref": "corner_delta.schema.json" }
  }
}
```

Cues that fail validation are dropped, not emitted — that is the
mechanical safety against the prototype's pedantry deficit.

### 4. Learning Plan (cold → hot path)

Hard cap: **50 KB**. Validated by `learning_plan.schema.json`.
Generated by `apps/cloud-backend`, consumed by `apps/edge-daemon`,
visualized by `apps/paddock-dashboard`. Air-gapped transport
envelope in `paddock_sync_envelope.schema.json` carries the plan
plus a signature for the connection-handshake safe-gate (PRD §7).

## Phase 0 lock — what to ship first

Phase 0 of any V2 implementation work freezes:

1. All 8 JSON schemas under `schemas/`.
2. The CornerPhase classifier signature (Python + TS, returning the
   same enum for the same inputs).
3. The CornerDelta API (Python + TS).
4. The LearningPlan validator (Python + TS), with the 50 KB cap
   enforced.
5. Golden test fixtures under `tests/golden/` — one Sonoma lap of
   real telemetry + the corresponding hand-curated CornerPhase /
   CornerDelta outputs. Both language implementations test against
   the same fixtures.

Implementations land after the schemas freeze. No feature work in
`apps/*` may import a DEL contract that isn't yet locked here.
